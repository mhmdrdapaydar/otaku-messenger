# پیام‌رسان اوتاکو

پیام‌رسان فارسی با پشتیبانی از گفت‌وگوی خصوصی، گروه‌ها و کانال‌ها. رابط کاربری راست‌به‌چپ است و برنامه با PHP و MySQL اجرا می‌شود.

## نکته مهم درباره فایل‌ها

هیچ فایل پیوستی در این برنامه روی سرور پیام‌رسان بارگذاری یا ذخیره نمی‌شود. پیوست‌ها فقط به‌صورت **لینک HTTPS از دامنه‌های مجاز** نمایش/ارسال می‌شوند؛ دامنه را مدیر در جدول `allowed_domains` مدیریت می‌کند. در پنل ورود JSON نیز بارگذاری فایل غیرفعال است. اگر می‌خواهید رسانه‌ای به اشتراک بگذارید، آن را در فضای میزبانی دلخواه خود قرار دهید و فقط لینک آن را ارسال کنید.

## نیازمندی‌ها

- PHP 8.1 یا جدیدتر، با افزونه‌های PDO و `pdo_mysql`
- MySQL 8 یا MariaDB سازگار
- وب‌سرور با پشتیبانی PHP (Apache/Nginx)

## راه‌اندازی

1. یک پایگاه داده و کاربر MySQL بسازید.
2. نمونه SQL موجود در `bzhpbuxh_Otaku_db.sql` را فقط در پایگاه داده خودتان وارد کنید. این فایل خروجی فعلی دیتابیس است و ممکن است داده‌های واقعی داشته باشد؛ پیش از عمومی‌کردن مخزن، داده‌های خصوصی را از dump پاک کنید یا آن را با نسخه schema-only جایگزین کنید.
3. متغیرهای محیطی `DB_HOST`، `DB_NAME`، `DB_USER` و `DB_PASSWORD` را در تنظیمات هاست تعریف کنید. `.env.example` صرفاً نمونه است و PHP به‌طور خودکار فایل `.env` را نمی‌خواند.
4. سایت را از ریشه پروژه با PHP 8.1+ اجرا کنید. برای توسعه محلی می‌توانید از `php -S 0.0.0.0:8000` استفاده کنید.
5. TLS/HTTPS را در وب‌سرور فعال کنید؛ کوکی نشست در HTTPS به‌صورت امن تنظیم می‌شود.

## تنظیم دامنه‌های رسانه

مدیر می‌تواند دامنه‌های مجاز را از پنل مدیریت ثبت کند. لینک پیوست باید با `https://` شروع شود و میزبان آن در `allowed_domains` باشد. خود برنامه فایل را دریافت، پروکسی یا ذخیره نمی‌کند.

## امنیت و استقرار

- اطلاعات اتصال پایگاه داده را فقط در متغیرهای محیطی هاست نگه دارید؛ اعتبارنامه‌های قدیمی داخل نسخه‌های قبلی کد را افشاشده فرض و آن‌ها را تعویض کنید.
- از دیتابیس و فایل SQL نسخه پشتیبان خصوصی تهیه کنید و نسخه‌های دارای اطلاعات کاربران را در مخزن عمومی قرار ندهید.
- از HTTPS، محدودسازی دسترسی پنل مدیریت، و به‌روزرسانی منظم PHP/MySQL استفاده کنید.
- خطاهای اتصال دیتابیس به کاربر جزئیات داخلی نشان نمی‌دهند و جزئیات فنی فقط در لاگ سرور ثبت می‌شود.
